Add a custom game from a CSV

For a TCG that isn't on tcgcsv, upload a CSV of its cards. The first row is the header — each column name becomes an entry field for that game. Recognized columns (name, number, set, rarity, price, url, image) are used for matching; every other column is kept as a custom field. The file name becomes the game's name in the import dropdown and in Database Match. Re-uploading a file with the same name replaces that game's data.

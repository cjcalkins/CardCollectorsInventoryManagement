Batch OCR Import
This button stays disabled until all 9 card tiles are aligned. When clicked, it sends the 9 processed filenames plus the selected template to the batch OCR route, which creates one inventory record per card.
Manual Corner Selection
Click the four corners of the card in any order, then click Process with Selected Corners to save the corrected aligned image for that slot. This can be used on fallback or auto-aligned tiles.

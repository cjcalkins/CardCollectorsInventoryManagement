Export migration bundle

Creates a portable .tar.gz containing every table (streamed, memory-safe), an image manifest, the PostgreSQL schema, an importer script, and a README — everything the desktop build needs. Image files aren't included (they can be huge); the importer syncs them to object storage from your image folder.

The bundle can contain marketplace and mailbox credentials. Store and transfer it securely.
Migration steps
1
Provision PostgreSQL 14+ on a dedicated machine (and optionally S3/MinIO object storage for images).
2
Export the bundle above and copy it to that machine, then extract it.
3
Run pip install psycopg2-binary then python import_to_postgres.py --dsn "postgresql://user:pass@host/db" --bundle .
4
To move images too, add --images-dir, --s3-endpoint, and --s3-bucket (needs boto3).
5
Point the desktop application at the same database and bucket. Full details are in README_MIGRATION.md inside the bundle.
